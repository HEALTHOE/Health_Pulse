# HealthPulse — District Health Monitoring & Analytics Dashboard

Synthetic HMIS-style data → Validation/ETL → PostgreSQL → Indicator Engine →
Analytics → Performance → Alerts → FastAPI REST API → React Dashboard.

- **Backend:** `backend/` (FastAPI, SQLAlchemy 2.x, PostgreSQL, Pydantic v2)
- **Frontend:** `frontend/` (React + Vite, built by teammate — backend team never touches it)
- **Docs:** `docs/` (API contracts, architecture, database)
